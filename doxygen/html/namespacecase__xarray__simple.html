Detailed Description

CaseXarray demo using SimplePhysicsTQ (no PHYEX required)

Creates an idealised 90-level atmosphere and runs a short simulation
with the all-or-nothing saturation adjustment and K-gradient turbulence.

Usage:
    python case_xarray_simple.py
