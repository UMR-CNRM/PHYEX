## History

The physics was first developed for the Meso-NH model.

Then, a part of the physics have been used to build the AROME model.

The last evolution was to extract the physics to build the independent PHYEX package.

## Content

The following parametrisations are included in the PHYEX package (see the MesoNH documentation for references):

 - turbulence scheme
 - shallow convection scheme
 - microphysics schemes (ICE3/ICE4 and LIMA)

In addition to the parametrisations source code, the package provides:

 - offline test programs (testprogs)
 - a python package (pyphyex) with a python binding of the main routines and a 1D model (phyex1d)
 - tools to prepare the source code for the different models and to check the contributions
